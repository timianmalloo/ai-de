Q0 — what is being measured
==============================================================================
Grid            : 200 cols x 50 rows = 10,000 cells
Frames per case : 60
Frame budget    : 16.7 ms at 60fps, 33.3 ms at 30fps
Rendering       : offscreen via DrawingVisual + RenderTargetBitmap,
                  so the number is WPF's cost and not the compositor's.
Typeface        : Cascadia Mono

Q2 — PARSE: can a VT stream be consumed at the 1 MiB/s budget?
==============================================================================
  stream: 1.00 MiB of representative VT output
  parsed in 0.4 ms  =>  2360.7 MiB/s
  printable=1,013,245  escapes=4,129  newlines=16,400
  OK  2361x the 1 MiB/s budget on a single thread.

==============================================================================
Verdict
==============================================================================
Fastest draw path: GlyphRun per line at p95 6.64 ms (151 fps ceiling).

RESULT: owning a WPF renderer is VIABLE on throughput. A full 200x50
  redraw fits inside a 60fps frame with margin, so the renderer is not
  the constraint — the parser and the coalescing policy are.
