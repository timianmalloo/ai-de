How this documentation stays honest

Every artifact under docs/ carries typed YAML frontmatter, and docs/docs-index.js is derived from it — never hand-edited. A pull request fails if the derived index disagrees with the frontmatter it came from, if a typed link dangles, or if an artifact's review-by date has passed. The freshness gate is docs-graph.py freshness; the graph validator is docs-graph.py validate.

The API reference and the four diagram families are regenerated by /document; coverage and confidence for the last run are in `_meta.json`.
