Static craft findings, not suppressions

The detector scanned the nonempty HTML. Three Minor reports remain and are interpreted in context:

  • Hairline border + wide shadow: only modal/floating elevation uses the existing dialog token;

docked panes and the continuous document remain flat. Do not remove boundary visibility just to satisfy the heuristic.

  • Cramped padding on outer app wrapper: a native window's title/content/status tiling meets its

edge. Text-bearing children carry their own insets; adding a padded page around the shell would change the medium. Rendered view/overflow checks cover the intended boundary.

  • Flat type hierarchy, 12–22px: this is the established dense desktop ramp, with 15px prose and

22px document title, not a marketing hero. The reviewer inspected the focal hierarchy. No off-token display scale was introduced to game the detector.

No rule was disabled. Token values and type remain governed by DESIGN.md. The token preview contains 56 hex color values and 38 declared text-pair checks; translucent roles remain in the canonical design language.
