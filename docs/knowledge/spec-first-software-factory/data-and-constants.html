Thresholds and measures

What the evidence does and does not establish

Flagged gap: no universal safe human-review cutoff was established. A diff-size limit is an operational bound; a model confidence filter is a workflow heuristic; code coverage measures execution, not obligation completeness. These are not interchangeable. Anthropic internal risk tiers are one organization's policy, not a standard to import unchanged. Internal practice, plugin filter, ultrareview limits.

Verified operating snapshot: current ultrareview docs describe default limits of 500 changed files and 8,000 changed lines, subject to the actual refusal's effective limits. They are not proposed review safety limits for AI-DE. No monetary estimate is used in the proposal.

Definitions and denominator rules — proposed

MeasureNumerator / denominator / scopeInterpretation
Requirement evidence coverageCriteria with reviewed meaningful oracles / applicable criteria at one spec versionLink presence alone does not establish meaningful evidence
Branch coverageExecuted instrumented branches / eligible branches, exclusions retainedNot semantic completeness
Mutation strengthRaw killed/survived/timeout/invalid counts and selected populationEquivalent mutants require disposition; preserve runner formula
First-pass rateTests passed on attempt one / tests attempted once in window/environmentDo not include retry recovery in numerator
Retry-recovered rateFirst-failed then recovered tests / tests eligible for retryClassification, not a causal flake probability
Review attentionActive human time plus waiting time, rounds and dispositionsPair with escapes/reverts/recovery outcomes
EfficiencyWall time, CPU and cost per run plus repeated setupParallel durations cannot be summed as wall time

Counts are additive only over disjoint populations; rates are non-additive. Missing denominator or window means not recorded, not zero. Flake quarantine does not erase failures. Never auto-delete tests merely because coverage overlaps: platform/boundary checks may be purposeful. Mutation semantics, retry semantics.
