What changed

  • Labels removed. At the real 56 px column width a 9 px caption under a 20 px glyph clipped: "Coordinate" → "ordina", "Explore" → "xplor". The rail is now icon-only — the VS Code / JetBrains activity-bar idiom (Jakob's Law).
  • No meaning lost. Discoverability moves to the tooltip; the accessible name stays on AutomationProperties.Name, so a screen reader still announces "Explore", "Coordinate", "Compose", "Audit".
  • Softer active state. The active item is an accent glyph on a raised rounded pill with no hard border (the border read as a clunky box); inactive items are muted on transparent.
  • Comfortable targets. 44 × 44 px (WCAG 2.5.8), icon 20 → 22 px for presence now that it carries the button alone.
